# GitHub (github.com)

Yazılım barındırma ve sürüm kontrol platformu. Araştırma bağlamında işlevi iki tane: (1) **replikasyon kodu** — `github.com/<kullanıcı>/<repo>` biçimindeki depo, makalenin yöntemini çalıştırılabilir hâle getirir; (2) **araç yayını** — açık kaynak araştırma altyapıları (görüşme platformları, sınıflandırıcılar, veri boru hatları) burada yayımlanır ve DOI'li arşiv kopyası genellikle Zenodo üzerinden alınır.

**Künye notu:** GitHub depoları sürümlenmez (branch/commit hareket eder) — atıf yapılacaksa belirli bir commit hash'i veya Zenodo'nun ürettiği DOI kullanılmalıdır. Bu vault'ta kod bağlantısı verilen kayıtlarda depo adresi `note` alanına yazılır, `resolved_url` yapılmaz; aksi hâlde kaynak künyesi makale yerine depoyu gösterir.
