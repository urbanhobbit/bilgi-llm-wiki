# Defining Web pages, Web sites and Web captures | Internet Archive Blogs

**Source:** [https://blog.archive.org/2016/10/23/defining-web-pages-web-sites-and-web-captures/](https://blog.archive.org/2016/10/23/defining-web-pages-web-sites-and-web-captures/)

## Summary

Vinay Goel tarafından Ekim 2016'da Internet Archive Blogu'nda yayımlanan bu yazı, web arşivleme alanında temel kavramları tanımlamaktadır: web sayfası, web sitesi ve web capture. Internet Archive'ün 20 yıllık web arşivleme deneyimine dayanan yazı, 510 milyardan fazla zaman damgalı web nesnesinin nasıl kategorize edildiğini açıklamaktadır. Yazının yayımlandığı tarihte Internet Archive, 361 milyondan fazla web sitesinden 273 milyar web sayfasını 15 petabayt depolama alanında arşivlemiştir.

## Key Points

- Web arşivleme terminolojisi standardizasyonu
- Internet Archive'ün metodolojisi
- 273 milyar web sayfası, 361 milyon web sitesi
- Dijital koruma ve uzun vadeli erişilebilirlik

## Turkey Context

Internet Archive'ün web arşivleme standartları ve tanımları, Türkiye'deki dijital arşivleme çalışmaları için referans niteliği taşımaktadır. Türkiye'de Milli Kütüphane ve Devlet Arşivleri Başkanlığı tarafından yürütülen web arşivleme projeleri, Internet Archive'ün belirlediği standartları temel almaktadır. BTK'nın internet düzenlemeleri kapsamında tutulan kayıtlar ve TÜİK'in dijital istatistikleri, bu tür tanımlamaların Türkiye bağlamında da önemini göstermektedir.
